# Included Lives — Painel do candidato

Abra `index.html` no navegador. Interface em HTML, CSS e JavaScript, responsiva, baseada na imagem de referência. Usa Font Awesome por CDN (ícones exigem internet).

## Estrutura
- `index.html`: telas e estrutura
- `css/painel.css`: estilos responsivos
- `js/painel.js`: navegação e interações
- `assets/logo.png`: arquivo de logo de referência disponibilizado no projeto

## Avisos
Os dados de entrevista, candidatura e vagas são fictícios. As alterações do currículo e das preferências são salvas somente no `localStorage` do navegador. Não existe autenticação, envio de mensagens ou comunicação com servidor. O layout pode precisar de rolagem em telas pequenas para preservar a acessibilidade e legibilidade.
