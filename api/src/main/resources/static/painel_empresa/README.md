# Included Lives — Painel completo da empresa

Abra `index.html` no navegador. Seções: visão geral, minhas vagas, candidaturas, banco de talentos, perfil da empresa, orientações e boas práticas, mensagens e ajuda. Gerenciamento de vagas com abas de candidaturas, descrição, acessibilidade e histórico; formulários para criar/editar vagas e atualizar etapas.

**Atenção:** protótipo de frontend com dados fictícios. Alterações são salvas no `localStorage` deste navegador; não há autenticação, banco de dados, envio de mensagens, convites ou candidaturas reais. Font Awesome e Inter dependem de conexão à internet.

Estrutura: `index.html`, `css/painel-empresa.css`, `css/modulos.css`, `js/painel-empresa.js`, `assets/logo.png`.
